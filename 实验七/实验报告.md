## 3. 实验原理

### 3.1 语义分割 (Semantic Segmentation)
语义分割是计算机视觉中的一项核心任务，其目标是为图像中的每个像素分配一个类别标签（如“背景”、“数字1”、“数字2”等）。与目标检测（Object Detection）不同，语义分割不仅需要知道图像中有什么物体，还需要精确地勾勒出物体的边界。在本实验中，我们的任务是对包含多个手写数字的 MNIST 图像进行分割，识别出每个像素属于哪个数字（0-9）或是背景。

语义分割的挑战在于它需要同时解决“是什么”（分类）和“在哪里”（定位）的问题。传统的分类网络（如 AlexNet, VGG）通过全连接层输出一个全局的类别标签，丢失了空间信息。而语义分割网络（如 FCN, U-Net, SegNet）则通过全卷积结构，保留了空间维度，从而能够输出与输入图像尺寸相同的像素级预测图。

### 3.2 SegNet 网络架构
SegNet 是一种专为语义分割设计的深度卷积编码器-解码器架构。其核心特点如下：

*   **编码器 (Encoder)**：
    *   由一系列卷积层、批归一化层、ReLU 激活层和最大池化层组成。
    *   **作用**：提取图像的高层语义特征，同时通过池化操作逐步降低特征图的空间分辨率，增大感受野。
    *   **关键机制**：在执行最大池化（Max Pooling）时，SegNet 会记录下每个窗口中最大值所在的**位置索引（Indices）**。这是 SegNet 与其他分割网络（如 FCN）最大的不同之处。

*   **解码器 (Decoder)**：
    *   结构与编码器对称，由最大反池化层、卷积层、批归一化层和 ReLU 激活层组成。
    *   **作用**：将低分辨率的特征图逐步恢复到原始图像的尺寸，并生成最终的分割掩码。
    *   **关键机制**：利用编码器阶段保存的**最大池化索引（Indices）**进行非线性上采样（Max Unpooling）。这种方法不需要学习额外的参数，既减少了模型参数量，又能较好地保留边缘等高频细节信息。

*   **SegNetLite (简化版)**：
    *   本实验实现的是 SegNet 的简化版本 `SegNetLite`。
    *   它包含 4 个下采样块和 4 个上采样块。
    *   输入图像经过编码器逐步压缩（64x64 -> 32x32 -> 16x16 -> 8x8 -> 4x4），通道数逐步增加（3 -> 32 -> 64 -> 128 -> 256）。
    *   解码器则进行相反的操作，最终通过一个 1x1 卷积层输出 11 个通道（背景 + 10个数字类别）的预测结果。

### 3.3 损失函数与优化
*   **损失函数**：实验使用 **CrossEntropy2D**（二维交叉熵损失）。它是标准交叉熵损失在像素级别的推广，用于衡量模型预测的像素类别分布与真实标签之间的差异。
*   **优化器**：使用 **Adam** 或 **SGD** 等优化算法，通过反向传播计算梯度，更新网络参数以最小化损失函数。

## 5. 实现 SegNetLite 类

本实验的核心任务是在 `lib/models/seg_net_lite.py` 文件中实现 `SegNetLite` 类。根据实验要求，我们需要构建一个包含 4 个下采样层和 4 个上采样层的简化版 SegNet 网络。

### 5.1 网络结构设计
网络整体结构遵循经典的 Encoder-Decoder 范式：
1.  **输入层**：接收 3 通道（RGB）的图像输入。
2.  **下采样路径 (Encoder)**：
    *   包含 4 个卷积块。
    *   每个块依次执行：`Conv2d` -> `BatchNorm2d` -> `ReLU` -> `MaxPool2d`。
    *   特征图尺寸逐层减半 (64->32->16->8x8->4)，通道数逐层翻倍 (3->32->64->128->256)。
3.  **上采样路径 (Decoder)**：
    *   包含 4 个反卷积块。
    *   每个块依次执行：`MaxUnpool2d` -> `Conv2d` -> `BatchNorm2d` -> `ReLU`。
    *   特征图尺寸逐层恢复 (4->8->16->32->64)，通道数逐层减半 (256->128->64->32->32)。
4.  **输出层**：
    *   通过一个 1x1 卷积层将特征图映射到 11 个类别通道（背景 + 10个数字）。

### 5.2 关键代码实现与解析

#### 5.2.1 初始化函数 (`__init__`)
在初始化阶段，我们利用 PyTorch 的 `nn.ModuleList` 动态构建了下采样和上采样层。

```python
def __init__(self, kernel_sizes=[3, 3, 3, 3], down_filter_sizes=[32, 64, 128, 256],
        up_filter_sizes=[128, 64, 32, 32], conv_paddings=[1, 1, 1, 1],
        pooling_kernel_sizes=[2, 2, 2, 2], pooling_strides=[2, 2, 2, 2], **kwargs):
    super(SegNetLite, self).__init__()
    
    # ... (参数初始化)

    # 1. 构建下采样层 (Encoder)
    current_in_channels = input_size
    for i in range(self.num_down_layers):
        # 卷积层: 提取特征，通道数增加
        layers_conv_down.append(nn.Conv2d(current_in_channels, down_filter_sizes[i], 
                                        kernel_size=kernel_sizes[i], padding=conv_paddings[i]))
        # 批归一化层: 加速收敛
        layers_bn_down.append(nn.BatchNorm2d(down_filter_sizes[i]))
        # 最大池化层: 关键点是 return_indices=True
        # 必须保存最大值的索引位置，用于后续的上采样恢复
        layers_pooling.append(nn.MaxPool2d(kernel_size=pooling_kernel_sizes[i], 
                                         stride=pooling_strides[i], return_indices=True))
        current_in_channels = down_filter_sizes[i]

    # ... (ModuleList 封装)

    # 2. 构建上采样层 (Decoder)
    current_in_channels = down_filter_sizes[-1]
    for i in range(self.num_up_layers):
        # 最大反池化层: 恢复特征图尺寸
        # 需要在 forward 中传入对应的 indices 才能精确恢复形状
        layers_unpooling.append(nn.MaxUnpool2d(kernel_size=pooling_kernel_sizes[i], 
                                             stride=pooling_strides[i]))
        # 卷积层: 调整通道数
        layers_conv_up.append(nn.Conv2d(current_in_channels, up_filter_sizes[i], 
                                      kernel_size=kernel_sizes[i], padding=conv_paddings[i]))
        # 批归一化层
        layers_bn_up.append(nn.BatchNorm2d(up_filter_sizes[i]))
        current_in_channels = up_filter_sizes[i]

    # ... (ModuleList 封装)

    # 3. 最终分类层
    # 使用 1x1 卷积将通道数映射为类别数 (11类: 背景 + 0-9数字)
    self.conv_final = nn.Conv2d(up_filter_sizes[-1], 11, kernel_size=1)
```

**实现细节分析**：
*   **`return_indices=True` 的核心作用**：这是 SegNet 实现中最关键的一行代码。在 `nn.MaxPool2d` 中开启此选项，使得池化层不仅输出最大值（Max Values），还输出最大值在原始特征图中的索引位置（Indices）。这些索引记录了特征图中“最显著”特征的空间位置，对于后续在解码器中精确恢复物体边界至关重要。
*   **层级对应与参数设计**：下采样层的输出通道数 (`down_filter_sizes`) 与上采样层的输入通道数设计得恰好匹配，保证了数据流的连贯性。例如，Encoder 最后一层输出 256 通道，Decoder 第一层输入也是 256 通道。
*   **动态网络构建**：使用 `nn.ModuleList` 而不是普通的 Python list 来存储层。这是因为 `nn.ModuleList` 可以正确注册网络中的子模块，使得 PyTorch 的 `autograd` 机制能够追踪这些层的参数，从而在反向传播时正确更新权重。如果使用普通 list，这些层的参数将无法被优化器识别。

#### 5.2.2 前向传播函数 (`forward`)
前向传播定义了数据在网络中的流动路径，特别是索引 (`indices`) 的传递。

```python
def forward(self, x):
    # 用于存储下采样过程中产生的最大池化索引 (indices)
    indices_list = []
    
    # Downsampling (编码器路径)
    for i in range(self.num_down_layers):
        x = self.layers_conv_down[i](x)
        x = self.layers_bn_down[i](x)
        x = self.relu(x)
        # 执行最大池化，并获取 indices (最大值位置)
        x, indices = self.layers_pooling[i](x)
        # 将索引保存到列表中，供解码器使用
        indices_list.append(indices)
        
    # Upsampling (解码器路径)
    for i in range(self.num_up_layers):
        # 执行最大反池化
        # 注意: 使用 indices_list[-(i+1)] 获取对应的下采样层的索引 (倒序使用)
        # 例如: 第1个上采样层对应第4个下采样层的索引
        x = self.layers_unpooling[i](x, indices_list[-(i+1)])
        x = self.layers_conv_up[i](x)
        x = self.layers_bn_up[i](x)
        x = self.relu(x)
        
    # 输出层: 生成最终的分割图 logits
    x = self.conv_final(x)
    return x
```

**实现细节分析**：
*   **索引存储 (`indices_list`)**：我们创建了一个列表来按顺序存储每个下采样块产生的索引。这些索引就像是“记忆”，记录了图像在被压缩过程中丢失的空间信息。
*   **倒序索引 (`indices_list[-(i+1)]`)**：由于 Encoder 和 Decoder 是对称结构，Decoder 的第 1 层对应 Encoder 的最后 1 层。因此，在解码过程中，我们需要以**倒序**的方式取出索引。例如，当 `i=0` (Decoder 第1层) 时，我们需要 `indices_list[-1]` (Encoder 最后一层的索引)。这种对称性确保了每一层上采样都能准确利用对应层级的空间信息。
*   **非线性上采样 (Max Unpooling)**：`layers_unpooling[i](x, indices)` 利用这些索引将特征值放回其在池化前的位置，其余位置补零。这种方式比简单的双线性插值更能保留边缘信息，因为它直接复用了编码阶段提取的强特征位置，从而在不需要学习额外参数的情况下实现了高效的上采样。

### 5.3 整体流程总结
`SegNetLite` 的整体工作流程可以概括为“压缩-记忆-恢复”三个阶段：

1.  **压缩与特征提取 (Encoder)**：
    *   输入图像经过 4 次连续的卷积和池化操作。
    *   **卷积**负责提取图像的纹理、形状等语义特征，通道数不断增加（从 3 到 256），特征表达能力越来越强。
    *   **池化**负责降低分辨率，增大感受野，同时通过 `return_indices=True` 记录下关键特征的空间位置（即“记忆”）。

2.  **记忆传递**：
    *   在 Encoder 阶段产生的 4 组 `indices` 被保存在 `indices_list` 中。
    *   这些索引不参与梯度计算，仅作为位置信息传递给 Decoder，充当了连接编码器和解码器的桥梁。

3.  **恢复与重建 (Decoder)**：
    *   Decoder 接收 Encoder 输出的低分辨率、高语义特征图。
    *   通过 4 次连续的反池化和卷积操作，利用传递过来的 `indices` 精确恢复特征图的空间尺寸。
    *   最终通过 1x1 卷积将高维特征映射为 11 个类别的概率分布图，完成像素级的分类任务。

这种设计使得 SegNet 在保持较高分割精度的同时，显著减少了参数量（因为上采样不需要可学习的参数），非常适合对计算资源敏感的场景。

### 6.3 训练过程关键代码段解释
在 `image_segmentation/train_mnist.py` 中，训练循环是模型学习的核心:

```python
    # 1. 定义损失函数和优化器
    criterion = CrossEntropy2D(ignore_index=255)
    optimizer = optim.Adam(model.parameters())

    # ... (数据加载器初始化)

    # 2. 训练循环 (Epoch Loop)
    for epoch in range(train_epochs):
        # train for one epoch
        # 调用 lib.core.function.train 函数进行单轮训练
        train(train_loader, model, criterion, optimizer, epoch,
              args.out_dir, writer_dict, args)

        # 3. 定期验证 (Validation)
        if (epoch + 1) % args.eval_interval == 0:
            # evaluate on validation set
            # 调用 lib.core.function.validate 函数在验证集上评估
            perf_indicator = validate(val_loader, val_dataset, model,
                                      criterion, args.out_dir, writer_dict, args)

            # 4. 保存最佳模型 (Model Checkpointing)
            if perf_indicator > best_perf:
                best_perf = perf_indicator
                best_model = True
            else:
                best_model = False
        
        # ... (保存 checkpoint)
```

*   **损失函数 (`CrossEntropy2D`)**：我们使用了自定义的二维交叉熵损失函数，并设置 `ignore_index=255`。这意味着在计算损失时，标签为 255 的像素（通常代表背景或无效区域）将被忽略，不参与梯度计算。
*   **优化器 (`Adam`)**：使用 Adam 优化器来更新模型参数，它结合了动量法和自适应学习率，通常比 SGD 收敛更快。
*   **训练与验证分离**：代码清晰地将训练逻辑 (`train`) 和验证逻辑 (`validate`) 分离。在每个 Epoch 结束后，立即在验证集上测试模型性能 (`perf_indicator`，通常是 mIoU)，并根据验证结果决定是否保存当前模型为“最佳模型” (`best_model`)。这是一种标准的防止过拟合和保存最优解的策略。

### 6.4 训练过程分析
训练脚本会自动执行以下步骤：
1.  **初始化**：加载 `SegNetLite` 模型，并将其移动到计算设备（CPU 或 GPU）。
2.  **数据加载**：通过 `DataLoader` 读取训练集数据。
3.  **迭代优化**：
    *   **Forward**：将图像输入模型，得到预测结果。
    *   **Loss**：计算预测结果与真实标签之间的交叉熵损失。
    *   **Backward**：反向传播计算梯度。

### 7.3 验证过程关键代码段解释

    model.eval()
    
    # ... (初始化变量)

    # 2. 禁用梯度计算
    with torch.no_grad():
        for i, (input, target) in enumerate(val_loader):
            # ... (数据维度调整)

            # 3. 模型推理
            output = model(input)

            # ... (计算 Loss)

            # 4. 获取最终预测结果
            # get_final_preds 通常包含 argmax 操作，将概率图转换为类别索引图
            preds = get_final_preds(output.detach().cpu().numpy())

            all_preds.extend(preds)

*   **`model.eval()`**：这是一个非常关键的操作。它会将模型切换到评估模式。对于 SegNet 中使用的 `BatchNorm2d` 层，这意味着它将使用训练期间统计的全局均值和方差，而不是当前批次的统计量。这保证了推理结果的稳定性。
*   **`torch.no_grad()`**：在验证阶段，我们不需要更新参数，因此禁用梯度计算可以显著减少显存占用并加速计算。
*   **`calc_IoU`**：这是评估的核心。IoU（交并比）计算公式为 $IoU = \frac{Intersection}{Union} = \frac{TP}{TP + FP + FN}$。`calc_IoU` 函数会计算每个类别（0-9及背景）的 IoU，然后取平均值得到 mIoU。mIoU 越接近 1，说明分割效果越好。

### 8.3 可视化过程关键代码段解释
`visualize_simple.py` 的核心流程包括数据预处理、推理和绘图。

```python
    # 1. 加载与预处理数据
    # 读取 .mat 文件
    data = loadmat(args.data)
    # 调整维度顺序: (H, W, C) -> (C, H, W) 以符合 PyTorch 格式
    image = data['imgMat'].transpose([3, 2, 0, 1]).astype(np.float32)
    
    # 归一化: 必须使用与训练时相同的均值和方差
    mean = np.array([0.485, 0.456, 0.406], dtype=np.float32).reshape(1, 3, 1, 1)
    std = np.array([0.229, 0.224, 0.225], dtype=np.float32).reshape(1, 3, 1, 1)
    image_norm = (image - mean) / std

    # 2. 模型推理
    with torch.no_grad():
        image_tensor = torch.from_numpy(image_norm)
        output = model(image_tensor)
        # argmax: 在通道维度(dim=1)上取最大值的索引，得到预测的类别图
        predictions = output.argmax(dim=1).numpy()

    # 3. 可视化绘图
    # 使用 matplotlib 创建 1x3 的子图
    fig, axes = plt.subplots(1, 3, figsize=(15, 5))
    
    # 显示原图
    axes[0].imshow(img_display)
    
    # 显示真实标签 (使用 vis_segments 将类别索引映射为颜色)
    axes[1].imshow(vis_segments(gt_mask, 11))
    
    # 显示预测结果
    axes[2].imshow(vis_segments(pred_mask, 11))
    axes[2].set_title(f'Prediction (mIoU: {miou:.3f})', ...)
```

*   **数据维度变换**：`.mat` 文件中的图像数据通常是 `(H, W, C)` 格式，而 PyTorch 需要 `(N, C, H, W)` 格式。代码中的 `transpose` 操作完成了这一转换。
*   **归一化一致性**：这是一个容易被忽视但至关重要的细节。推理时的归一化参数（mean, std）必须与训练时完全一致，否则模型看到的图像分布将发生偏移，导致预测效果极差。
*   **`argmax(dim=1)`**：模型的输出是 `(N, 11, H, W)` 的概率分布（logits）。我们需要在通道维度（代表 11 个类别）上找到概率最大的那个类别的索引，从而得到最终的分割掩码 `(N, H, W)`。
*   **`vis_segments`**：原始的标签和预测结果都是 0-10 的整数索引，直接显示是一张灰度图，很难分辨。`vis_segments` 函数的作用是将这些整数索引映射到预定义的彩色调色板上，使得不同的数字显示为不同的颜色，便于观察。
